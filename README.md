# Portal Data Bidang Pencegahan & Kesiapsiagaan — DESTANA + EWS

Versi ini mempertahankan modul DESTANA dan menambahkan/menyempurnakan modul Early Warning System (EWS).

## EWS
- Data utama dari Google Sheets `INPUT DATA EWS`.
- Filter dashboard Kabupaten/Kota mengendalikan indikator dan grafik EWS.
- Kartu: EWS Terpasang dan EWS Terpasang Tahun Berjalan.
- Grafik sumber pendanaan dan total per jenis EWS.
- Grafik sebaran EWS Kabupaten/Kota menggunakan nama wilayah pada sumbu X, dengan tombol Lihat semua dan pengurutan.
- Grafik pemasangan per tahun dengan rincian sumber pendanaan.
- Tabel EWS dengan filter mandiri: pencarian, Kabupaten/Kota, Jenis EWS, Tahun Pemasangan, dan Sumber Dana.
- Filter tabel tidak mengubah dashboard utama.

## DESTANA
Kode dan tampilan modul DESTANA dipertahankan dari versi sebelumnya.
